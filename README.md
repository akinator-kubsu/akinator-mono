# Структура

## AkinatorLogicService

> реализация FR1.2, FR1.3, FR1.4

Этот сервис является ядром игры "Акинатор", реализованным на Prolog. Он предоставляет HTTP API для управления игровым процессом: получение следующего вопроса на основе предыдущих ответов, попытка угадать персонажа, а также добавление нового персонажа и нового уникального вопроса, если текущий набор ответов не позволяет однозначно идентифицировать объект или если пользователь хочет различить два очень похожих объекта. Сервис также включает реализацию дополнительной уникальной игровой фичи, доступной через его API.

## AkinatorApiService

> реализация FR2.2, FR2.3, FR2.4, FR3.2, FR3.3, FR3.4

Этот RESTful сервис, разработанный на ASP.NET, служит центральным бэкендом для приложения "Акинатор". Он отвечает за управление пользователями (регистрация, аутентификация), сбор и хранение информации об игровых сеансах, включая загаданных персонажей, ответы на вопросы и добавленных пользователями персонажей и вопросов. Сервис также интегрирует F# модуль для выполнения аналитических запросов к базе данных и предоставляет API для получения этой статистики, а также для сохранения данных, связанных с дополнительной фичей из FR1.4.
